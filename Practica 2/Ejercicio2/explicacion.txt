--Info agregada con IA--

Agrupación y Cohesión (Encapsulamiento)
Si guardaras los datos en variables sueltas (nombre1, email1, edad1), 
la información estaría desconectada. El objeto reúne bajo una misma entidad (usuario)
todas las propiedades que le pertenecen a esa persona. Es el equivalente a crear una 
instancia de una clase en Java o Programación Orientada a Objetos.

Mapeo Directo a Formato JSON (Ideal para AJAX/API)
El estándar absoluto en la web para enviar datos hacia un Backend o API Gateway es el formato
JSON (JavaScript Object Notation). Un objeto JS se convierte a JSON de forma instantánea con
una sola línea (JSON.stringify(usuario)), quedando listo para ser enviado en las etapas 
avanzadas de tu guía.

Escalabilidad para Múltiples Registros
Si la aplicación necesita registrar a 100 personas, no creás 100 conjuntos de variables. 
Simplemente creás una lista (const listaUsuarios = []) e insertás (push) cada objeto usuario 
adentro. Es el equivalente exacto a tener una lista del tipo ArrayList<Usuario> en Java.
