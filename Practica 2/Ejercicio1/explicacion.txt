1.	El objeto JavaScript construido.
Arme un objeto JS utilizando los datos ingresados, siendo los mismos guardados en variables.
Luego creamos la constante usuario y le asignamos los valores.


2.	El JSON generado.
Mediante el metodo JSON.stringify() pasandole como parametro el objeto js creado, podemos "compactar" el objeto y sus valores
para que sea solo texto.



3.	Una explicación de la diferencia entre el objeto JavaScript y el JSON obtenido.
El objeto js podemos decir que es una instancia viva dentro de la web , pero al momento de querer mandar los datos hacia el Backend,
el mismo solo recibe texto como dato, por ende deberiamos de usar la funcion JSON.stringify() para poder realizar la transformacion.



4.	Una descripción del momento del flujo en el que sería necesario convertir los datos a JSON.
Se utiliza para enviar los datos al servidor y este lo pueda entender, por ejemplo cuando enviamos los datos de un formulario y 
esperamos una respuesta.











--Info agregada por la IA--

JSON.stringify() es una función nativa de JavaScript que hace algo muy concreto:
convierte un objeto de JavaScript en una cadena de texto (string) en formato JSON.

¿Por qué existe y para qué se usa?
En la memoria de tu navegador, un objeto de JavaScript es una estructura de datos viva y compleja.
Sin embargo, cuando querés enviar datos a un Backend a través de la red (usando AJAX o fetch), la red
no puede transportar "objetos vivos"; solo puede transportar texto plano.

JSON.stringify() actúa como un "empaquetador": toma tu objeto y lo transforma en un texto con formato 
universal que cualquier servidor (escrito en Java, Python, Node.js, etc.) puede recibir y entender.
